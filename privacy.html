Privacy policy

Personal tracker · last updated 28 October 2026

Whose data

Personal tracker is used only by its owner, and the only Google account it reads is its owner's own. It holds no data about anyone else.

What it reads

It has read-only access to its owner's Gmail (the gmail.readonly permission). It searches only for shipping and delivery emails from the last two weeks. It never sends, changes or deletes email.

What it keeps

From those emails it keeps only what it needs to track each parcel:

  • the courier and the tracking number;
  • the shop's name and, when the email gives one, the item's name;
  • the delivery status and when it changed;
  • a list of the emails it has already read, so it doesn't read them twice.

These details are stored in its owner's private Personal tracker site, which only its owner can sign in to. The emails themselves are read on its owner's own computer and are not stored. The one exception: if a run fails, that computer's error log can hold the emails the run was reading, and the log is deleted after 14 days.

Sharing

Personal tracker does not sell, share or transfer this data to anyone, and it does not use it for advertising.

Google API data

Personal tracker's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Stopping access

Its owner can remove Personal tracker's access to Gmail at any time from the Google Account's connections page.
